## Para subir a GitHub y Vercel

Sube directamente los archivos `index.html`, `styles.css`, `config.js`, `app.js` y la carpeta `assets/` a la **raíz** del repositorio. Importa el repositorio en Vercel con Framework Preset `Other`, sin comando de compilación.

`config.js` permite ajustar nombres, fecha, lugares, mapas y textos. El reproductor intenta iniciar la música al abrir la carta; según el navegador puede requerir pulsar el control flotante.

La vista previa autocontenida (`invitacion_fatima_humberto_final_floral.html`) se entrega por separado y no es necesaria para Vercel.
